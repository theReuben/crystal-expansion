-----------------------------------------------------------------------
PRECONDITION: build with gmake, not /usr/bin/make
-----------------------------------------------------------------------
Apple's /usr/bin/make is GNU Make 3.81. With the merged rule files it does not
fail -- it hangs, spinning at 100% CPU with no child processes. `sample` shows
deep self-recursion inside make's implicit-rule search: 3.81's search is
exponential in the number of pattern rules, and the merge roughly triples them
(graphics_file_rules.mk 313 -> 869 lines, spritesheet_rules.mk 25 -> 829).
GNU Make 4.4.1 (homebrew `gmake`) runs the identical rule set to completion in
3.8 seconds. This is a toolchain constraint, not a defect in the merge; see
decision D4. All Phase 2 builds must use gmake.
